# هارنس (Harness)

هارنس محیط توسعه، آزمایش و مدیریت ابزارهای ایکاروس است.

## ابزارها

### Idea Architect — معمار ایده

ابزار تبدیل ایده خام به طرح پروژه، درخت وظایف بازگشتی و صف اجرای قابل اعتبارسنجی. پیاده‌سازی نسخه 0.1 در مسیر زیر قرار دارد:

`Tools/Idea Architect/`

این نسخه شامل پروتکل JSON با نام ITP-1.0، رابط مستقل برای مدل‌های System 1 و System 2، مدل آزمایشی آفلاین، برنامه‌ریز بازگشتی، ثبت پروژه و کشف کنترل‌شده کاندیداهای Skill در GitHub است. جزئیات نصب، اجرا و محدودیت‌ها در README همان ابزار آمده است.

## اصول

- هارنس بخشی از مخزن اصلی ایکاروس است، نه جایگزین هسته آن.
- ابزارها باید تا حد امکان مستقل، قابل‌آزمایش و قابل‌تعویض باشند.
- هر ابزار مستندات، ورودی‌ها، خروجی‌ها و محدودیت‌های خودش را خواهد داشت.
- مدل‌ها برنامه و پیشنهاد تولید می‌کنند؛ کد میزبان اعتبارسنجی، مجوزدهی و اجرای واقعی را کنترل می‌کند.
