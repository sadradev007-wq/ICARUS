# معمار ایده (Idea Architect)

این پوشه محل توسعهٔ ابزار «معمار ایده» در هارنس ایکاروس است.

## مأموریت

تبدیل ایده‌های خام به طرح‌های روشن، ساختاریافته و قابل‌اجرا.

## محدودهٔ نسخهٔ اولیه

- دریافت و ثبت ایده
- روشن‌سازی مسئله، هدف و محدودیت‌ها
- شکستن ایده به اجزا و زیرمسئله‌ها
- ترسیم ارتباط میان اجزا
- تولید طرح اولیه و گام‌های اجرایی
- نگهداری تاریخچهٔ تغییرات ایده

## وضعیت

اسکلت اولیه؛ هنوز پیاده‌سازی نرم‌افزاری انجام نشده است.

## اصل طراحی

معمار ایده باید یک ابزار مستقل و ماژولار باشد تا بعداً بتوان آن را از طریق رابط مشخصی به هستهٔ شناختی ایکاروس متصل کرد.
